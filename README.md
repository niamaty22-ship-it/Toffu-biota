# 🌿 Toffu Biota — A Tiny Pixel-Art Nature World

*A little garden of pixels, curiosity, and science.*

Welcome to **Toffu Biota**, a whimsical nature-inspired web project where pixel art meets scientific curiosity! 🌱

Toffu Biota is an interactive, pixel-art-inspired website designed to celebrate the beauty of nature while making science feel approachable, playful, and fun to explore. From charming plants and flowers to little creatures hidden throughout the world, the project brings together a cozy visual style and real scientific content in one small digital garden.

The idea is simple: learning about the natural world shouldn't feel like reading a textbook all the time. Sometimes, it can start with a little curiosity and a world you want to explore.

## ✨ Why I Made It

I created Toffu Biota as a way to combine my love for science, nature, and creative web development into one project.

I wanted to build something that felt alive, welcoming, and a little magical — a place where the charm of pixel art could meet the wonder of the real world. Nature is full of fascinating details, from the smallest organisms to the ecosystems that connect all living things, and I wanted to reflect some of that wonder through a playful digital experience.

This project was also an opportunity for me to learn by building. As I worked on Toffu Biota, I explored web development, experimented with visual design, organized image assets, and learned how to bring different pieces of a website together using HTML, CSS, and JavaScript.

**My goal:** to create a little corner of the internet that feels cozy, sparks curiosity, and reminds people that science can be beautiful, creative, and fun. 🌼

## 🌸 Features

- 🎨 **Pixel-art aesthetics** — a soft, playful visual style inspired by cozy digital worlds.
- 🌱 **Nature-inspired design** — plants, flowers, animals, and other little details that bring the garden to life.
- 🔬 **Real science content** — nature-themed information that encourages curiosity and learning.
- 🪴 **Asset Garden** — a visual gallery for browsing the project's pixel-art assets.
- 🔎 **Asset search** — search through the gallery to find specific assets more easily.
- 💻 **Built for the browser** — explore the project without installing a separate application.

## 🎮 How to Explore Toffu Biota

### Option 1: Play online

The easiest way to explore is through the live website:

**[🌿 Visit Toffu Biota](https://niamaty22-ship-it.github.io/Toffu-biota/)**

Open the website in your browser and explore the different sections available.

### Option 2: Run it on your computer

Want to explore the project locally or look at the code? Here's how!

**What you'll need**
- A web browser
- Git (optional, if you download the project as a ZIP instead)

**Method A — Clone the repository**

1. Open a terminal.
2. Run the following commands:

   ```bash
   git clone https://github.com/niamaty22-ship-it/Toffu-biota.git
   cd Toffu-biota
   ```

3. Open the project folder.
4. Open `index.html` in your browser to launch the website.

**Method B — Download the project**

1. Open the [GitHub repository](https://github.com/niamaty22-ship-it/Toffu-biota).
2. Click **Code → Download ZIP**.
3. Extract the ZIP file.
4. Open the extracted folder and launch `index.html` in your browser.

If any features behave differently when opened directly, try using a local development server through VS Code, such as the Live Server extension.
